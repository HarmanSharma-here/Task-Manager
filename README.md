# Task Manager

A lightweight task manager built with HTML, CSS, and vanilla JavaScript. Tasks are saved in your browser's local storage, so they remain available after you reload the page.

## Features

- Add tasks
- Mark tasks as complete by clicking them
- Delete tasks
- Persist tasks in browser local storage

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Project files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — task behavior and local storage
